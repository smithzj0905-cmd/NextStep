# NextStep — Phase 1 MVP

Goal: validate whether strangers will upload confusing paperwork and find the result useful.

This is a mobile-friendly web MVP. It includes:
- Landing page
- Document upload / paste text
- Demo analysis flow
- Action-plan result screen
- Deadline/reminder CTA
- Privacy-oriented copy
- Feedback capture
- Basic acquisition/SEO content starter

IMPORTANT:
The included analyzer is a demo so the site works without an API key. Replace the demo analyzer with your preferred AI API before public launch. For legal, tax, medical, financial, or government documents, clearly label results as informational and encourage verification with the issuing organization.

## Run locally

1. Install Node.js 20+
2. `npm install`
3. `npm run dev`
4. Open http://localhost:3000

## Phase 1 success target

Do not optimize for downloads. Track:
- visitors
- document analyses
- repeat analyses per user
- feedback submissions
- % saying they would use it again
- % willing to pay

Target: 50 real users and at least 100 real document analyses before expanding the product.

## Suggested zero-dollar launch

1. Deploy the web app on a free hosting tier.
2. Post genuinely useful answers in relevant communities; do not spam.
3. Publish the included problem-specific pages/posts.
4. Ask early users what document types they need most.
5. Add analytics only after the core upload flow works.
